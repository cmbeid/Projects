Dragonwilds Save Editor

Wear any item from your inventory, the Fire Cape included, by moving it into your equipment in the character save, and unlock recipes. Everything happens in this page; your save never leaves your computer.

Before you start

  1. Quit the game fully. It keeps your character in memory and overwrites the file when it exits.
  2. Your character saves are in %LOCALAPPDATA%\RSDragonwilds\Saved\SaveCharacters, one <CharacterName>.json per character. Paste that path into the File Explorer address bar, or press Win+R and paste it there.
  3. Copy the whole SaveCharacters folder somewhere safe before you change anything.
  4. If Steam Cloud puts the old file back, turn it off for the game while you swap the edited one in (Steam → RuneScape: Dragonwilds → Properties → General).
