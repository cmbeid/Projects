Dragonwilds Save Editor

Change gear, items and recipes in a RuneScape: Dragonwilds character save. Everything happens in this page; your save never leaves your computer.

Before you start

  1. Go back to the game's main menu (or quit). While you are in a world the game keeps your character in memory and writes over the file.
  2. Your saves are in %LOCALAPPDATA%\RSDragonwilds\Saved\SaveCharacters, one <CharacterName>.json per character. Paste that path into the File Explorer address bar.
  3. Copy that folder somewhere safe before you change anything.
